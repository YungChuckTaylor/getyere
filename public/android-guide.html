Small glossary. No assumed knowledge.+
Repository (repo)
The source-code folder stored on GitHub.
Terminal
The command app on your computer, such as PowerShell on Windows or Terminal on macOS/Linux. Run commands from the project folder.
Package name
The app’s permanent identity: com.getyere.app.
Supabase
The existing service for accounts, reminders, file storage and server functions.
FCM
Firebase Cloud Messaging: the service used to send Android push notifications.
APK / AAB
An APK installs on a phone. An Android App Bundle (.aab) is uploaded to Play, which creates APKs for users’ devices.
Keystore / upload key
A private signing file and key used to authorize release uploads. Keep it outside Git with a secure backup.
Play App Signing
Google’s system for signing the apps delivered to users; its certificate can differ from your upload certificate.
Fingerprint
A public identifier of a signing certificate, used by integrations such as verified app links. It is not a private key.
versionCode
The integer Google uses to order Android releases. Increase it for every new upload.
Test track
A controlled Play distribution channel for internal or closed testing before production.
ANR
“Application Not Responding”: a freeze reported in Play’s quality tools.
