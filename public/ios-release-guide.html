Small glossary. No assumed knowledge.+
Repository (repo)
The folder of source code stored on GitHub.
Terminal
The Mac app where you paste commands. Open Applications → Utilities → Terminal.
Bundle ID
The app’s unique identity. Yere uses com.getyere.app.
Supabase
The existing service that stores Yere accounts, reminders and server settings.
Signing
Apple’s way of checking which developer owns and distributes the app.
APNs
Apple Push Notification service. It delivers alerts to the iPhone.
Archive
A packaged release build made by Xcode for uploading to Apple.
TestFlight
Apple’s app for privately installing and testing an unreleased app.
App Store Connect
Apple’s website for your listing, builds, testers and review submission.
Yere · Remember together.Submission is not approval. Apple makes the review decision.
